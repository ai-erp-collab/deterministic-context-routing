# Shared Knowledge

Use this folder for facts, patterns, contracts, and workflow notes that apply
across modules.

Keep pages short and link to deeper evidence instead of copying large source
bodies.

- `glossary/`: term cards, one per cross-module term (template: [glossary-term-page.md](../../templates/wiki/glossary-term-page.md)).
- `recipes/`: platform techniques, one page per technique.
- `patterns/INDEX.md`: ready solutions: task -> pattern or recipe page -> owner module.
